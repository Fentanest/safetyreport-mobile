# 통계 의미 검수

## 입력
statistics-spec, 현행 모델/집계 코드, 필터 상태, fixture, 표시 지표 목록.
사양이 비어 있으면 의미를 임의 확정하지 말고 현재 코드와 결정 항목을 분리한다.

## 규칙
- 내 신고와 전국 신고현황(Sunwi)을 혼합하지 않는다.
- 총 신고, 답변 완료, 수용/일부수용/불수용, 교통 처분을 서로 같은 분모로 가정하지 않는다.
- 신고월은 신고일, 답변월은 답변일을 사용하고 차트에 기준을 명시한다.
- 과태료 월별 합계는 부과일을 보유하는지 확인한다. 없으면 실제 부과월인 것처럼 표현하지 않는다.
- Client와 Standalone에 동일한 정의/필터를 적용한다. 데이터 부족/미지원은 조용히 다른 지표로 대체하지 않는다.
- 중복차량은 traffic/parking/other와 배타적인 네 번째 카테고리라고 가정하지 않는다.
- 대표건 정책과 취하 제외 설정의 적용 범위를 확인한다.
- 기관 평균의 단순 평균을 전체 평균으로 쓰지 않는다. 원시 표본 또는 유효 표본수로 가중한다.
- 답변 미완료를 0일 답변으로 넣지 않는다. 날짜 역전은 오류/제외 사유를 드러낸다.
- 미확인 금액과 0원을 구분한다. 문자열 '과태료'만 있는 값에서 금액을 만들지 않는다.
- 이전 기간 0/비교 기간 미확보/현재 미완료 월은 퍼센트 비교 규칙을 명시한다.
- 모든 숫자는 런타임 데이터/집계에서 산출한다. 시안의 3,037·58.6 등의 숫자를 하드코딩하지 않는다.

## 테스트
빈 데이터, 1건, 미답변, 취하만 있음, 중복군, 연도 경계, 잘못된 날짜, 금액 미확인, 평균 표본수 차이를 fixture로 검사한다.
총계/범례/막대·도넛 합계/상세표의 동일 조건 일치를 검증한다.
차트 선택→목록 drilldown 시 기준 날짜·기관·분류·위반법규 필터가 보존되는지 확인한다.

## 출력
지표별 정의/분모/날짜/필터/출처/시험결과, 발견한 오류와 영향 화면, 미확정 계약.
