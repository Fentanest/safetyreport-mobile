# UI 리뉴얼 설계 정본 (ui-renewal-spec)

상태: **시범 구현 반영(2026-09-24)** — D-01~D-04 사용자 결정 완료, 시범 범위(테마·신고 카드·대시보드·상단 탭·통계 요약) 구현. 작성 2026-09-24, base `c64be69a`.
기능 기준은 [feature-matrix.csv](feature-matrix.csv), 통계 의미는 [statistics-spec.md](statistics-spec.md), 에셋은 [asset-manifest.csv](asset-manifest.csv).
이 문서는 **보이는 모습**만 정한다. 데이터 흐름·콜백·필터·내비게이션은 바꾸지 않는다(`PROJECT_RULES.md` §1).

## 1. 시각 정본
- 정본 이미지: `reference/mobile dark.png`(REF-11, 다크), `reference/mobile white.png`(REF-12, 화이트 대응안). 사용자가 선택한 짙은 네이비·블루 컨셉.
- 보조 참고: `design tokens.png`(토큰), `UI COMPONENT KIT.png`(컴포넌트 형태), `badge.png`(배지 형태), `board.png`(빈/오류 상태), `guide.png`(차트 스타일).
- 보조 이미지가 정본과 충돌하면 정본 두 장이 우선이고, 기능은 코드가 우선이다. 아래 "결정 필요"로 넘긴다.
- 모바일과 PC는 색·글꼴·상태색 규칙을 공유하되 레이아웃은 별개다. PC 구성(사이드바·표·페이지네이션)은 이 앱에 넣지 않는다.

### 상태·처분 색 (D-02: 선택지 c — 모바일 먼저 변경, 서버 웹은 별도 추종)
`lib/server_palette.dart` 값을 토큰 보드 상태색으로 바꿨다. 서버 웹이 따라오기 전까지 **웹과 모바일 배지 색이 다르다**.

|---|---|---|
| 보완요청 | `#FD7E14` | `#F97316` |

**중요:** 시안처럼 기준색 채움 + 흰 글자로 그리면 10개 중 8개가 WCAG AA 미달(2.15~3.76:1)이다. 그래서 배지·상태 카드는
`StatusTone`(틴트 배경 + 기준색에서 명도만 옮긴 글자, 4.5:1 이상 자동 보정)으로 그린다. 보장은 `test/theme/theme_contrast_test.dart`.
도넛 조각 안 흰 % 글자도 같은 이유로 없애고 범례에 비율을 표시한다.

## 3. 타이포그래피 (D-04 결정: 기기 기본 글꼴)
- 폰트 에셋을 추가하지 않는다(`fontFamily` 미지정). 시안의 Noto Sans KR/Pretendard 충돌은 이 결정으로 해소.
- 참고: 서버 웹 `web/templates/base.html:23` 은 `Noto Sans KR` 을 지정한다(`guide.png` 의 "기존 서비스와 동일한 Pretendard" 는 사실과 다름).
- 골든 테스트만 호스트 Noto Sans CJK 를 로드해 렌더한다(`test/support/ui_harness.dart`).
- 스케일은 토큰 보드 값을 기준으로 한다: Display 32/48, H1 24/36, H2 20/32, H3 18/28, Body1 16/24, Body2 14/20, Caption 12/16.

## 4. 형태·간격
- 간격 8px 계열(4, 8, 12, 16, 24, 32, 48, 64). Radius sm 4 / md 8 / lg 12 / xl 16 / 2xl 24.
- 그림자·글로우는 카드 강조에만 쓰고 **대량 목록·차트에는 blur/glow를 쓰지 않는다**(스크롤 성능). profile 빌드로 확인한다.

## 6. 화면별 적용 범위
- 시범(1차): 테마 계층 + 신고 카드 + 대시보드 요약 카드/처리 현황 + 통계 요약 일부, 라이트/다크 실렌더.
- 이후: 신고내역 → 신고관리(별점/감시/중복/수정) → 알림 → 파일 → 동기화/크롤링 → 설정/권한/로그인 → 지도(테마만).
- 진입 경로가 없는 `SearchScreen`, `WatchlistScreen`, `SunwiScreen` 래퍼는 리뉴얼 대상에서 뺀다(패널은 사용 중).

## 7. 시안에서 제외한 것 (feature-matrix UNS-*)
신고하기/신규 접수, 시스템 공지, 일반 파일 업로드, 신고 레코드 "선택 삭제", PC 사이드바·테이블·페이지네이션·전역 검색,
시안 수치(3,037·58.6일·+12% 등) 하드코딩, 중복차량을 네 번째 카테고리로 합산한 월별 차트, 날짜 근거 없는 월별 과태료 차트.
