### 개선
- 신고 상세 화면의 줄 간격을 줄여 한눈에 더 많이 보이게 했습니다.
- 서버 연결 모드에서 신고 검색과 페이지 이동의 대기 시간과 데이터 사용량을 줄였습니다. 이 개선은 검색 기능을 지원하는 서버에 연결했을 때 적용됩니다.
- 위반 내용에 맞춰 과태료 금액의 일부 오타를 바로잡아 표시·집계하는 범위를 넓혔습니다.

### 버그 수정
- 지역명이 붙은 이륜차 번호판을 승용차로 잘못 판단해 추정 과태료가 틀리던 문제를 고쳤습니다.
- 단독 모드에서 같은 이륜차의 번호판 표기가 달라 중복차량으로 묶이지 않던 문제를 고쳤습니다.
