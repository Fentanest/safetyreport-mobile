### 새 기능
- 통계에 "전체" 분류 탭 추가(처음 열면 전체 선택): 모든 분류를 합친 기관·담당자 카드, 위반법규 선택 목록, 확정·추정 과태료를 따로 표시
- 서버 연결 모드에서 전체 탭은 PC 서버 3.4.1 이상에서 보임(이전 서버면 전체 칩을 숨기고 교통위반으로 열림)

### 버그 수정
- 통계 분류별 카드를 눌러 연 목록에 처리 중 신고까지 섞여 카드 건수보다 많던 문제(답변 완료 신고만 표시)
- 통계 분류를 바꾼 직후 월별 추이 차트를 만지면 오류가 나던 문제
