### 새 기능
- 답변에 위반법규가 여러 개 적힌 신고는 법규를 모두 저장하고, 법규 검색·선택 목록·상세 링크·통계를 법규별로 따로 찾기

### 개선
- 위반법규 인식 확대(약칭·괄호·연속 조문 등), 일반 안내·포상금 문구를 사건 법규와 구분
- 답변의 확정 과태료 금액 인식 확대(만원 단위·쉼표·전각 숫자 등), 조건부·서로 다른 금액은 확정하지 않음

### 버그 수정
- 완료된 신고의 처분이 비어 있거나 미확인으로 남던 경우 답변에 적힌 과태료 부과를 반영

### 업데이트 안내
- 새로 받는 답변부터 적용되며 기존 신고는 자동으로 다시 읽지 않음
- 서버 연결 모드의 법규별 검색은 PC 서버도 함께 업데이트 필요
