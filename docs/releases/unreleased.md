### 새 기능
- 커뮤니티 지도에 신고 상세 원본을 보내고 지도 서비스가 직접 정리(신고자 이름·연락처·아이디는 제외, 새 동의문에 동의한 뒤 적용)
- 새 동의 뒤 답변 완료 신고 전체를 한 번 전송(빠진 신고·별점·사진 촬영 시각을 먼저 채움, "원본 전송 n / N" 표시)

### 변경
- 공유 동의가 없거나 바뀐 동의문에 다시 동의하기 전에는 앱 사용 불가(카카오 로그인·신고 자료는 유지)
- 동의 상태를 확인할 수 없으면 마지막 확인부터 3일만 사용
- 동의 철회·카카오 연결 끊기·탈퇴 때 카카오 로그인 첫 화면으로(신고 자료 보존)

### 버그 수정
- 처음 설치 때 안전신문고 계정을 두 번 입력하던 문제
- 카카오 로그인 창을 닫고 오면 "처리 중..."에 멈춰 보이던 문제

### 업데이트 안내
- 새 동의문이 나오기 전까지는 지금처럼 사용
- 서버 연결 모드는 PC 서버 3.6.0 필요
