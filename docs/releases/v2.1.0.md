**나만의 안전신문고 Android 앱 v2.1.0 · 빌드 38**

### 새 기능
- 기존 기타 탭을 안전신고·생활불편·기타로 나누었습니다. 교통위반·주정차와 함께 다섯 가지 분류로 신고를 찾고, 통계·지도·엑셀 내보내기에서도 같은 분류를 이용할 수 있습니다.
- 단독 모드의 신고 내역 다시 불러오기가 백그라운드에서 진행됩니다. 대시보드에서 진행 상황을 확인하면서 다른 화면을 이용할 수 있습니다.

### 개선
- 차량번호 인식과 신고 종류별 추정 과태료 계산을 개선했습니다. 답변에 적힌 확정 금액과 추정 금액은 따로 표시합니다.
- 커뮤니티 서버가 불안정할 때 불필요한 반복 요청을 줄여 배터리와 데이터 사용을 줄이도록 개선했습니다.
- 커뮤니티 지도의 랭킹을 한 페이지에서 살펴볼 수 있도록 개편했습니다.

### 버그 수정
- 서버 연결 모드에서 앱을 켤 때마다 초기화 안내 화면이 잠깐 나타나던 문제를 수정했습니다.
- 다시 불러오는 도중 표시 필터를 바꾸면 작업이 중단되던 문제를 수정했습니다.
- 아직 검토 중인 신고를 완료로 잘못 표시하던 문제를 수정하고, 답변 내용과 진행 상태를 함께 확인하도록 개선했습니다.
- 이전 서버에 연결했을 때 새 분류 조회가 실패하던 문제와 서버 오류의 구체적인 안내가 보이지 않던 문제를 수정했습니다.

### 업데이트 안내
- 단독 모드는 업데이트 후 처음 실행하면 신고 내역을 한 번 다시 불러옵니다. 앱 구조 개선에 따른 추가적인 불가피한 조치입니다. 불편을 드려 죄송합니다. 진행 상황은 대시보드에서 확인할 수 있습니다.
- 서버 연결 모드는 PC 서버의 다시 불러오기 진행 상태를 따릅니다. PC 서버도 3.1.0으로 함께 업데이트해 주세요.
- 백업 복원은 같은 버전끼리 이용해 주세요. 자료를 가져올 수 없는 경우에는 이유를 안내합니다.
