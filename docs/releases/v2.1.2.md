### 버그 수정
- 서버 연결 모드에서 '신고 내역 다시 불러오기'를 시작할 때 휴대폰 로그인 화면만 반복되던 문제를 고쳤습니다. PC 서버의 커뮤니티 로그인이 필요하면 안내와 함께 '서버 커뮤니티 계정 로그인' 버튼을 보여 줍니다.
- 서버 계정 로그인 화면에서 돌아오면 다시 불러오기 상태를 새로 확인합니다.
- 이전 PC 버전에 연결했을 때도 휴대폰에 이미 로그인되어 있으면 서버 계정 로그인을 확인하도록 안내합니다.
