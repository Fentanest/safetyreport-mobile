**나만의 안전신문고 Android 앱 v2.2.0 · 빌드 175**

### 새 기능
- 목록·상세에 추정 과태료(법정 최저)와 확정액 구분 표시, 상세 근거 확인·엑셀 내보내기
- 단독 모드: 공유 동의 시 기존 지도 공유 자료에도 추정액 자동 반영

### 개선
- 단독 모드에서 번호판 표기가 다른 같은 차량도 묶기
- 위반 내용에 따른 과태료 오타 보정·집계 확대, 상세에서 원문 확인
- 서버 연결 모드 검색·페이지 이동 대기·데이터 사용량 감소
- 상세 줄 간격 축소, 앱 정보에 빌드 번호 표시

### 버그 수정
- 화면 꺼짐 시 답변 알림의 자동 크롤링·동기화 미시작 수정
- 종료된 크롤링의 대시보드 진행 중 표시 수정
- 이전 알림 실패로 새 답변 처리 지연·삭제한 확인 알림 반복 수정
- 지역명 있는 이륜차를 승용차로 오인한 추정액 오류·단독 모드 번호판 표기 차이로 중복차량 누락 수정

### 업데이트 안내
- 로그인 보호 개선: 오래된 버전은 로그인 정보 재입력·커뮤니티 연결 확인, 신고 자료·설정 유지
- 서버 연결 모드의 빠른 검색은 PC 3.3.0 이상 필요

앱은 Google Play 스토어에서 설치·업데이트해 주세요: https://play.google.com/store/apps/details?id=com.fentanest.mysafetyreport
