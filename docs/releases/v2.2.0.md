**나만의 안전신문고 Android 앱 v2.2.0 · 빌드 42**

### 새 기능
- 신고 목록·상세에 추정 과태료(법정 최저 기준)를 확정 금액과 구분해 표시합니다. 추정 근거는 상세에서 확인하고 엑셀로도 내보냅니다.
- 공유에 동의한 단독 모드는 기존 지도 공유 자료에도 추정 금액을 자동 반영합니다.

### 개선
- 단독 모드에서 번호판 표기가 조금 달라도 같은 차량의 신고를 한데 묶습니다.
- 과태료 금액의 일부 오타를 바로잡아 표시·집계하며, 상세에서 원문도 확인할 수 있습니다.

### 버그 수정
- 화면이 꺼진 동안 답변 알림을 받아도 자동 크롤링·동기화가 시작되지 않던 문제를 고쳤습니다.
- 끝난 크롤링이 대시보드에 계속 진행 중으로 보이던 문제를 고쳤습니다.
- 이전 알림의 처리 실패로 새 답변 처리가 지연되거나, 지운 확인 알림이 반복되던 문제를 고쳤습니다.

### 업데이트 안내
- 로그인 정보 보호 방식을 개선했습니다. 오래 업데이트하지 않았다면 안내에 따라 로그인 정보를 다시 입력하고 커뮤니티 연결을 확인해 주세요. 신고 자료와 앱 설정은 유지됩니다.
