  3. 테마 재생성 차단 — SQ-P01ThemeData 정적 캐시 + 루트 Selector. 몇 줄 수정으로 전체 재빌드를 없애는, 효과 대비 작업량이 가장 좋은 항목.
  4. 잘못 보이는 숫자·조건 바로잡기 — SQ-U01 · SQ-U02 · SQ-U09 · SQ-U12건수 배지, 드릴다운 필터 누수, 차트 축 잘림, 라벨 폭. 사용자 눈에 바로 보이는 표시 오류.
  5. 조작 계통 — SQ-U05 · SQ-U06 · SQ-U07 · SQ-U14뒤로가기는 대시보드로, "관리"는 탭 전환으로, 이중 손잡이 제거, 동영상 뒤 방향 복원.
  6. 가시성 — SQ-U03 · SQ-U04 · SQ-U13 · SQ-U08다크 지도 라벨, 큰 글자 넘침(1.3·2.0배 위젯 테스트 먼저), 상태 칩 대비, 모드별 빈 상태 문구.
  7. 네이티브·화면 수명 — SQ-B04 · SQ-B05 · SQ-B07 · SQ-B08 · SQ-B09소비형 서버 신호 순서, 메서드 채널 루트 등록, 크롤링 화면 폴링·dispose, 서버 변경 시 기능 목록 초기화와 저장 잠금, mounted 확인.
  8. 조회 비용 — SQ-P02 · SQ-P03 · SQ-P04 · SQ-P05데이터 변경 신호 분리, 엑셀 내보내기 isolate·페이지화, 백그라운드 폴링 정지, 지도 마커 캐시. 각 항목은 PerformanceTrace로 전후 계측 뒤 채택.
  9. 배치·메뉴 재구성 — SQ-U15 · SQ-U16 · SQ-U17 · SQ-U18 · SQ-U10 · SQ-U11대시보드 밀도, 앱바 통일, 설정 순서, 동기화 화면, 지도 출처 표기·권한 요청 시점. 화면 구성이 바뀌므로 시안 확인 후 진행.
  10. 계획 정비 묶음 — C등급 전체글자·색·모서리 토큰화, 빈 상태 공용 부품, 숫자 표기, 툴팁·터치 영역, Provider 구독 축소, 문서 정정.
Limitations

5. 점검 범위와 한계

  • 실행한 것: 전용 에뮬레이터(sr_uitest_api35)에 운영 앱과 분리된 패키지(…mysafetyreport.uireview, debug)로 설치해 Standalone 데모 데이터로 전 탭·설정·동기화·지도·상세·검색 시트를 조작하고 캡처했다. 라이트/다크, 글꼴 1.0/1.3/2.0배를 바꿔 보았다. 글꼴 배율과 다크 모드 설정은 1.0·라이트로 원복했고, 점검이 끝난 뒤 에뮬레이터를 정상 종료했다.
  • 실행하지 않은 것: Client 모드(실서버·로그인 사용 금지 규칙), 실제 동기화·별점 제출·업로드, 가로 모드·3버튼 내비게이션, profile 빌드 성능 계측, flutter test. "추정"으로 표시한 성능 영향은 수치가 없다.
  • debug 빌드 한계: ANR 1회와 긴 스플래시는 debug·소프트웨어 GPU·메모리 2GB 에뮬레이터에서 관찰한 것으로 제품 성능으로 일반화하지 않는다.
  • 정적 분석: flutter analyze(Flutter 3.47.5) 결과 error 0, warning 9(모두 test/storage/registry_vectors_test.dart 등 test 폴더의 불필요한 캐스트).
  • 기존 계획과의 관계: DB 교환·동기화·네이티브 알림 관련 27개 항목(DB-01~06, UI-01~04, N-01~09, S-01~08)은 기존 계획 문서에 있어 여기서 반복하지 않았다.
  • 코드 변경 없음: 이번 점검은 읽기와 시험 설치만 했다. 레포 파일은 바꾸지 않았다.
